Mon engagement

Numérique responsable

La création numérique a un impact réel sur l'environnement et la société. Cette page présente mes engagements et les pratiques appliquées dans ce portfolio.

Contenu numérique responsable

🌱

Éco-conception web

Ce site a été conçu en minimisant les ressources chargées : pas de framework CSS lourd, images optimisées et compressées, polices limitées à deux familles chargées via Google Fonts avec display=swap pour ne pas bloquer le rendu.

  • Images en format WebP ou JPEG optimisé
  • CSS organisé en fichiers séparés et minifiables
  • Chargement des librairies JS via CDN avec cache navigateur
  • Pas de tracking tiers ni de publicité
♿

Accessibilité (WCAG)

Le site respecte les recommandations WCAG 2.1 niveau AA pour être accessible au plus grand nombre.

  • Contrastes suffisants entre texte et fond (ratio ≥ 4.5:1)
  • Navigation au clavier complète (focus visible)
  • Balises ARIA pour les éléments interactifs
  • Textes alternatifs sur toutes les images
  • Respect de la préférence prefers-reduced-motion
  • Structure HTML sémantique (main, nav, section, article…)
📱

Responsive & mobile first

Le site s'adapte à tous les appareils : mobile, tablette, desktop. Un site responsive bien conçu évite de créer plusieurs versions, ce qui réduit la consommation de ressources.

  • Design mobile-first avec media queries progressives
  • Unités relatives (rem, %, vw) plutôt qu'absolues
  • Menu burger pour les petits écrans
  • Images adaptées à la taille d'affichage
🔒

Protection des données

Ce portfolio respecte la vie privée des visiteurs en collectant le minimum de données nécessaires.

  • Aucun cookie de tracking ou publicitaire
  • Formulaire de contact sans stockage de données tiers
  • Hébergement sur GitHub Pages (transparence de la chaîne)
  • Aucune revente de données personnelles
💡

Impact des créations 3D

La modélisation 3D et le rendu sont énergivores. J'essaie d'en tenir compte dans mes pratiques.

  • Optimisation des meshes pour réduire le nombre de polygones
  • Utilisation d'EEVEE (rendu temps réel) plutôt que Cycles quand possible
  • Réutilisation et mutualisation des assets entre projets
  • Sensibilisation aux enjeux d'impact du rendu 3D en production
